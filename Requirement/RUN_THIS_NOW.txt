================================================================================
                              TROUBLESHOOTING
================================================================================

PROBLEM: "Cannot connect to server"
FIX: 1. Ensure SQL Server service is running
    2. Services → MSSQL$SQLEXPRESS → Status = Started
    3. Close SSMS and reopen as Administrator

PROBLEM: "Database already exists"
FIX: Script handles this automatically (will skip creation)

PROBLEM: "Login failed"
FIX: Use Windows Authentication (not SQL Server auth)
    In SSMS → Authentication = Windows Authentication

PROBLEM: Script still fails
FIX: Manually drop database first:
    ALTER DATABASE VehicleDealerDB SET SINGLE_USER WITH ROLLBACK IMMEDIATE;
    DROP DATABASE VehicleDealerDB;
    Then run the script again
